# What is AI? — title page

The opening page for Jeff Yates's TEDxCOM talk "What is AI? A brief introduction to Neural Networks"
(College of Marin, COMP 138). A single dark title slide with the speaker block, a faint animated
2 → 8 → 5 network, a Begin button into Part 1 of the six-demo series, a roadmap of all six parts,
a QR code so the audience can follow along, and the same 2-minute talk timer as the demo pages.

Right arrow, space, or Page Down also begins the demos.

Live: https://professor-jeff.github.io/what-is-ai/
